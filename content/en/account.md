# Step 0: open an account

**The arena and local paper trading don't need an exchange account.**

You only need one to:

- practise on an exchange's testnet or demo trading (the next version of the safety shell supports this), or
- trade your own money later, if you decide to.

## Pick one

- [Binance: sign-up guide](/go/signup/binance?l=en&from=account-en)
- [OKX: sign-up guide](/go/signup/okx?l=en&from=account-en)

Stuck while signing up? [Ask the help bot](/go/help-bot?l=en&from=account-en)

> Signing up through these links gets you a trading fee discount, as shown by the exchange.

Exchanges don't serve every country. Check the exchange's official site.

## Once you have an account

- Only use the exchange's official website and app. Don't click links sent to you in chats.
- Turn on two-factor authentication.
- When you create an API key: allow reading and trading, never withdrawals; lock it to an IP address; start with testnet or demo keys.
- Never hand a key that can trade to anyone or any "bot platform". That includes us.
