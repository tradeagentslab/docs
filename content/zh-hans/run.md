# 零代码跑法

安全壳装在 AI 代理和行情之间：代理只能按几个按钮，下单的按钮都上了锁，每一笔都留签了名的记录。v0 只有模拟盘：代码里没有实盘这条路。

## 要准备什么

- 一台 Mac 或 Linux 电脑（Windows 以后支持）；
- 装好 Claude Code、Codex、OpenClaw 其中一个；
- Node 20 以上。

不要交易所账户，不要任何密钥。

## 一条命令装好

```sh
npx -y {{npm}} init
```

它做四件事：

1. 用各家自己的命令，把安全壳登记进你装的代理软件；
2. 装一个零代码模板：教代理“先看行情，再决定，写理由，在锁里下单，收盘写日记”；
3. 写默认配置：模拟盘，1 万 USDT 模拟资金；
4. 在你电脑上生成一把签名钥匙，账本用它签名。它不离开你的电脑。

想先看它会改什么，在后面加 `--dry-run`。

终端里要用 `{{cli}}` 这个命令，先装一次：

```sh
npm i -g {{npm}}
```

不想装，就把下面的 `{{cli}}` 换成 `npx -y {{npm}}`，效果一样。

## 装完对代理说什么

重开代理软件，然后对它说：

> 用 {{mcp}} 看看 BTC，模拟买 100 USDT。

代理会先看行情和账户，再下一个市价单，并写下理由。单子在下一根 1 分钟 K 线的开盘价成交，手续费 0.1%。价格用币安现货的公开行情。

## 锁

| 锁 | 默认 | 碰到了 |
|---|---|---|
| 币种 | BTC、ETH、SOL、BNB、XRP、DOGE 对 USDT，只做现货 | 别的一律拒 |
| 一笔 | 最少 10 USDT，最多权益的 10% | 拒 |
| 一个币 | 最多权益的 30% | 这个币只许卖 |
| 一天 | 当天（UTC）亏到 5% | 当天剩下的时间只许卖 |
| 总亏损 | 权益跌到初始资金的 70%（亏损 30%） | 自动急停 |
| 频率 | 每小时 12 单，每天 60 单 | 拒 |
| 死循环 | 一小时被拒 30 次 | 自动急停 |

没有提币、划转、杠杆、合约这些按钮，代理也改不了锁。

## 急停

```sh
{{cli}} halt
```

马上撤掉还没成交的单，之后的单一律拒。加 `--flatten` 会把持仓全部按市价卖成 USDT。

代理觉得不对也可以自己按急停，但只有人能恢复：

```sh
{{cli}} resume
```

它会让你在终端里打 yes 确认。

## 看账本

```sh
{{cli}} status
{{cli}} replay
{{cli}} verify
```

`status` 看账户；`replay` 按时间回放当天每一笔，带代理写的理由；`verify` 核对账本有没有被改过：每一行都带着上一行的指纹和签名，删改一行就对不上。

## 它防什么，不防什么

它防代理犯傻：手滑、循环下单、追涨加仓、亏了加倍下注、买名单外的币。

它防不了有意绕过的代理：在同一台电脑上，代理有你的权限，想绕总能绕过去。所以 v0 只连模拟盘。以后想用真钱，要三样一起：交易所那边的限制（子账户只放小钱、API 只开交易不开提币、绑 IP），钥匙不放在代理那台电脑上，再加安全壳。

## 卸载

```sh
npx -y {{npm}} uninstall
```

从代理软件里删掉，账本留在你电脑上。
