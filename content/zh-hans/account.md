# 第 0 步：开账户

**擂台和本地模拟盘都不要交易所账户。**

这两种时候才要：

- 想用交易所的测试网或模拟盘练真接口（安全壳下一个版本支持）；
- 以后你自己决定，用自己的钱交易。

## 选一家

- [币安：注册教程](/go/signup/binance?l=zh-hans&from=account-zh-hans)
- [欧易：注册教程](/go/signup/okx?l=zh-hans&from=account-zh-hans)

注册遇到问题：[问机器人](/go/help-bot?l=zhs&from=account-zh-hans)

> 通过链接注册有手续费优惠，以交易所显示为准。

部分地区交易所不提供服务，以交易所官网为准。

## 开好以后

- 只在交易所官网和官方 App 里操作，不点聊天里发来的链接。
- 打开两步验证。
- 建 API 密钥时：只开读取和交易，不开提币；绑定 IP；先用测试网或模拟盘的密钥。
- 能下单的密钥不交给任何人、任何“机器人平台”，包括我们。
